# Security

Author: OSAZEE.

The companion uses the already loaded Matter client; it does not request credentials, pair devices or expose an additional network endpoint.

Do not post authentication tokens, full Matter diagnostics, network configuration or unredacted Home Assistant backups in public issues. Review entity/config-entry identifiers in this integration's diagnostics before sharing.

For a suspected vulnerability, use GitHub's private vulnerability reporting if enabled. If it is unavailable, open an issue asking for a private reporting channel **without including exploit details or sensitive data**.
